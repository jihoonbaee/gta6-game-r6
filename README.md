Neon Harbor is an original 3D open-world crime game set in a bright harbor city at sunset. Rin Kade begins a first shift for Harborline Courier, with four jobs leading from a marked Solaris Vela sedan to Pier 04, a downtown meeting, and an escape to the Safehouse. Explore on foot or by car amid traffic and pedestrians, with wanted levels and responding police. Built with locally vendored Three.js r152, the static game runs without external assets or network requests. Controls: WASD or arrows to move or drive, mouse to look, E to enter or exit cars, Shift to sprint, Space for the handbrake, F to shoot, R to reload, right mouse to aim, and Escape to pause. Mission rewards track shift earnings; checkpoints use browser local storage.

## Run it

```sh
node serve.ts
# Open http://localhost:8080 in desktop Chrome.
# Package game/ and screenshots/ with Node.js 22 or newer:
MAKEFUN_OUTPUT_DIR=out node main.ts
```
